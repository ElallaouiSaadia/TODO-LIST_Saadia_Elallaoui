# 🚀 Projet Todo App

## 📌 Description
Cette application Todo App permet de gérer facilement des tâches quotidiennes.  
Elle permet à l’utilisateur de :

- Ajouter des tâches
- Marquer des tâches comme terminées
- Supprimer des tâches
- Filtrer les tâches (Toutes / Terminées / En attente)
- Activer le mode sombre

---

## 🎯 Objectif du projet
Le but de ce projet est de créer une application simple de gestion de tâches en utilisant :

- HTML
- CSS
- JavaScript

---

## 🧩 Fonctionnalités

- ➕ Ajouter une tâche
- ✔ Marquer une tâche comme terminée
- ❌ Supprimer une tâche
- 🔍 Filtrer les tâches :
  - Toutes
  - Terminées
  - En attente
- 🌙 Mode sombre / clair
- 💾 Sauvegarde des tâches avec LocalStorage

---

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage (navigateur)

---

## 🎨 Design (Figma)
L’interface utilisateur a été conçue avec Figma.  
Elle contient :

- Une zone d’ajout de tâches
- Une liste de tâches
- Des boutons de filtre
- Un bouton de mode sombre
